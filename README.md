《阿里王统记》由古格大堪布阿旺扎巴撰写，约成书于公元1497年。作者曾赴卫藏师从宗喀巴大师，后返回阿里。本书从印度王统与吐蕃赞普世系写起，随着历史变迁，吐蕃王室后裔迁居阿里，在新的土地上延续祖先的世系与王统，并逐渐形成以不同地域为中心的统治格局，以及对西藏佛教后弘期缘起与发展的记载。
本书最为重要的内容之一，是对西藏佛教后弘期缘起与发展的记载，益西沃等王室成员为佛教复兴作出了极为重要的努力，从王室护持、远赴印度求法，到译师翻译经典、高僧弘扬教法，再到寺院与僧团重新建立，阿里所推动的是一场关系到西藏佛教命运的深刻复兴。正是这一时期的努力，使佛法传承重新获得坚实而完整的依托，使西藏佛教得以重新建立自身的发展根基，并由此开启了此后千年绵延发展的历史。今天西藏佛教的重要教法传承与宗派发展，都与这一时期所奠定的基础有着密不可分的联系。
除王统与佛教事业外，本书还记载了阿里地区历代王室的世系、王权传承、政治活动、疆域变化及其与周边地区的关系，为研究西藏西部的历史提供了珍贵资料。不过，本书约成书于1497年，距离十七世纪古格地区政权的最终覆亡尚有一百余年，关于此后的相关历史，还需要参考《拉达克王统记》，两书相互参照，有助于进一步理解西部西藏地区此后的历史变迁。
此次翻译，希望尽可能忠实地呈现原文的历史脉络与记述内容，并采用较为通行的汉语佛教术语，使读者能够更直接地理解书中人物、事件与教法传承。对于原文中难以确认的专名与史实，则尽量避免过度推断，以尊重史料本身的记述边界。
谨以此译本，呈现吐蕃王统在阿里的延续，以及这一历史进程中所孕育的佛教复兴事业。希望读者能够通过本书，重新认识阿里在西藏历史中的地位，也能够理解仁钦桑布、阿底峡以及益西沃等先贤所开创的事业，如何使西藏佛教在经历重大历史变迁之后重新焕发生机，并为此后漫长岁月中的弘扬与传承奠定根基。
